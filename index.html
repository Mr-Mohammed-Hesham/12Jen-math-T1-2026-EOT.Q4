📐 القوانين الأساسية

خاصية الضرب الصفري:
If ab = 0, then a = 0 or b = 0
إذا كان حاصل الضرب صفراً، أحد العاملين صفر
تحليل ثلاثي الحدود:
ax² + bx + c = (px + q)(rx + s)
ابحث عن عددين حاصل ضربهما ac ومجموعهما b
فرق المربعين:
a² - b² = (a-b)(a+b)
مربع كامل:
a² ± 2ab + b² = (a ± b)²
مجموع/فرق مكعبين:
a³ ± b³ = (a ± b)(a² ∓ ab + b²)
العامل المشترك:
ax + ay = a(x + y)
أخرج العامل المشترك أولاً
